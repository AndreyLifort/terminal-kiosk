# terminal-kiosk

Стартовая страница-заглушка для крипто-терминала. Работает в Chromium kiosk-режиме на тачскрин-терминале 19" под Debian 13.

**Три экрана:**
1. Стартовый — две большие кнопки: «Купить криптовалюту» / «Оплатить нейросети».
2. Сбор телефона — поле + цифровая клавиатура, отправка в Google Sheets.
3. «Спасибо» — автовозврат на стартовую через 5 сек.

Idle-reset на экране сбора: 30 секунд бездействия → стартовая.

## Стек

Чистый HTML/CSS/JS без билда, без зависимостей. Один HTML + один CSS + два JS. Сделано так специально:
- Терминал слабый (Celeron E3300, 2 ГБ RAM, Intel GMA X4500) — никакого React/Vite на нём.
- Переезд на любой партнёрский хостинг = `rsync` или загрузка через панель.

## Структура

```
terminal-kiosk/
├── index.html              # SPA-каркас
├── styles.css              # стили + клавиатура
├── app.js                  # роутер, idle, отправка, anti-nav
├── keyboard.js             # цифровая клавиатура
├── config.example.js       # шаблон APPS_SCRIPT_URL
├── config.js               # реальный конфиг (gitignored)
├── assets/                 # SVG-иконки и лого
├── apps-script/            # бэкенд на Google Apps Script + инструкция
└── deploy/                 # kiosk.sh + инструкция установки на терминал
```

## Быстрый старт

```bash
cd terminal-kiosk
python -m http.server 8080
# открыть http://localhost:8080 в Chrome
```

Без `config.js` с реальным `APPS_SCRIPT_URL` сайт работает в **демо-режиме** — телефоны сохраняются в `localStorage` пользователя. Чтобы лиды шли в Google Таблицу:

1. Настроить Apps Script по `apps-script/README.md`.
2. Скопировать `config.example.js` → `config.js`, вставить `APPS_SCRIPT_URL`.

## Тестирование под разрешение терминала

Терминал — GeneralTouch USB 19" (обычно 1280×1024, 5:4). В Chrome:
- DevTools → Toggle device toolbar
- Custom size 1280×1024
- Включить touch emulation

Прогнать чек-лист:

- [ ] Стартовая: обе кнопки кликабельны, не вылезают за экран
- [ ] «Купить криптовалюту» / «Оплатить нейросети» ведут на экран ввода (разные `?src=`)
- [ ] Тап на поле телефона поднимает клавиатуру snizu
- [ ] Маска `+7 (___) ___-__-__` форматируется при наборе
- [ ] Backspace удаляет последнюю цифру
- [ ] Кнопка «Оставить номер» неактивна, пока 10 цифр не введены
- [ ] После отправки — экран «Спасибо» с прогресс-баром, через 5 сек возврат на стартовую
- [ ] На экране ввода через 30 сек простоя — автоматический возврат на стартовую
- [ ] При настроенном `APPS_SCRIPT_URL` в Google Таблице появляется строка

## Тест kiosk-флагов локально

```bash
# Windows
"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk --app=http://localhost:8080

# Выход — Alt+F4
```

Внутри страницы должны быть заблокированы: правый клик, выделение, F11, F12, F5, Ctrl+*, Alt+*.

## Деплой на GitHub Pages

1. `git init && git add . && git commit -m "initial terminal-kiosk"`
2. Создать репо на GitHub, push в `main`.
3. В репо: **Settings → Pages → Source: Deploy from branch → main / /(root)**.
4. URL вида `https://<user>.github.io/<repo>/` готов через минуту.

Все пути в HTML/CSS/JS — **относительные**, поэтому сайт работает и в подпапке репо, и в корне партнёрского хостинга, без правок.

## Переезд на хостинг партнёров

Когда партнёры согласуют макет:
1. Зипнуть содержимое `terminal-kiosk/` (без `.git`, `apps-script/`, `deploy/`).
2. Развернуть в корне их хостинга (FTP / SFTP / панель).
3. Обновить `config.js` если меняется Google-таблица.
4. Поменять `KIOSK_URL` в `deploy/kiosk.sh` и перезалить его на терминал.
