# Google Apps Script — приём лидов

Скрипт `Code.gs` принимает POST с телефоном и записывает строку в Google Таблицу. Это бесплатный «бэкенд без сервера» — не требует ни хостинга, ни API-ключей.

## Шаг 1. Создать Google Таблицу

1. Зайти на [drive.google.com](https://drive.google.com), создать пустую таблицу с именем `terminal-leads`.
2. Переименовать первый лист в `Leads` (двойной клик по вкладке внизу).
3. Заполнить шапку (строка 1):

| A | B | C | D | E | F |
|---|---|---|---|---|---|
| timestamp | phone | source | userAgent | terminalId | clientTs |

4. Скопировать `SHEET_ID` из URL таблицы:

```
https://docs.google.com/spreadsheets/d/<ВОТ ЭТО SHEET_ID>/edit
```

## Шаг 2. Создать скрипт

1. В таблице: меню `Extensions → Apps Script`.
2. В открывшемся редакторе удалить заготовку, вставить содержимое `Code.gs` из этой папки.
3. Заменить `PASTE_SHEET_ID_HERE` на скопированный `SHEET_ID`.
4. Сохранить (Ctrl+S), назвать проект `terminal-leads-api`.

## Шаг 3. Развернуть как Web App

1. Кнопка `Deploy → New deployment` (правый верхний угол).
2. Иконка шестерёнки → выбрать **Web app**.
3. Заполнить:
   - **Description:** `v1 prod`
   - **Execute as:** `Me` (ваш аккаунт)
   - **Who has access:** `Anyone` (анонимный POST — без этого терминал не сможет отправлять)
4. `Deploy`. При первом деплое Google попросит подтвердить доступ к таблице — соглашаемся (Advanced → Go to project (unsafe), это нормально для своих скриптов).
5. Скопировать **Web app URL** — он выглядит как:

```
https://script.google.com/macros/s/AKfycb...-q5w/exec
```

## Шаг 4. Прописать URL на сайте

В `terminal-kiosk/config.js`:

```js
window.CONFIG = {
  APPS_SCRIPT_URL: 'https://script.google.com/macros/s/AKfycb.../exec',
  TERMINAL_ID: 'atm-001',
};
```

## Шаг 5. Проверка

1. **Health check:** открыть Web app URL в браузере без параметров — должно вернуться `{"ok":true,"service":"terminal-leads"}`.
2. **Тест отправки:** открыть сайт терминала, нажать «Купить криптовалюту», ввести телефон, отправить.
3. В Google Таблице должна появиться новая строка с заполненными колонками.

## Обновление скрипта

Когда правите `Code.gs`:
1. Сохранить (Ctrl+S).
2. `Deploy → Manage deployments` → карандашик у текущего деплоя → `Version: New version` → `Deploy`.
3. URL остаётся прежним.

> ⚠️ Если просто сохранить без нового деплоя — изменения **не применятся** к публичному URL. Это типичная ошибка.

## Замечания по безопасности и квотам

- **Лимиты Apps Script:** 20 000 вызовов URLFetch в сутки и ~6 минут на один запрос. Для одного-нескольких терминалов это с большим запасом.
- **Антиспам:** Web app URL публичный, в теории кто угодно может слать POST. Если станет проблемой — добавьте простой `sharedSecret` в payload и проверку в `doPost`.
- **PII:** в Таблице будут хранится телефоны пользователей. Не открывайте доступ к таблице кому попало.

## Откат

Если что-то сломалось, в `Manage deployments` можно вернуться на предыдущую версию или временно «Archive» → терминал тогда будет складывать лиды в `localStorage` (offline-очередь).
